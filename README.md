# workspace-board

The phone view of the workspace live board (board 0.1.0). This repository holds **code only**: the page reads
issues straight from GitHub in your browser with a fine-grained token you paste once (kept in that browser's
localStorage). No data is stored or published here.

Generated from `git-global-workspace/board/ui` by `board/publish-pages.mjs`. Do not edit here; change the board
through `workspace-live-board-edit` in the hub.
